A股底部横盘启动选股 —— 当前筛选逻辑（v2.6.1，2026-10-18）
================================================================

【当前策略结构】
  主推      = v1.3 右侧启动 + 基本面向好（净利拐点，或净利改善且股东户数连降）
  其他观察  = v1.3 右侧启动中基本面未达主推的股票
  底部观察池 = v2.6 底部横盘（观察、不作入场依据）
  大盘状态  = 中证1000 在 MA120 下方 → "可关注"；在上方 → "谨慎"（上证指数 MA60 作第二参考）
  依据：策略选择建议-2026-10-18.md、大盘环境指标对比-2026-10-18.md。回测中"v1.3 + 基本面向好
  + 中证1000在MA120下方"通过全部稳健性检查（132 个信号，平均超额 +3.9%），目前处于模拟验证期。

本文描述每日任务 scripts/run_daily_screen_and_notify.py 当前实际执行的逻辑，与代码一致。
只用于研究观察池，不构成投资建议，不提供买卖点、仓位或评分。

----------------------------------------------------------------
一、每日流程
----------------------------------------------------------------
1. 交易日 17:00 运行（周末跳过；行情日期不是当天则跳过，不发送旧数据）。
2. 拉取全市场财务名单（东方财富）→ 剔除 ST / *ST / 名称含"退"的股票。
3. 拉取当日收盘快照（东方财富；失败时自动改用腾讯批量行情）。快照为空直接报错退出。
4. 逐只下载前复权日K（腾讯；失败回退新浪），当天结果缓存在 output/cache/kline/日期/，
   v2.6 和 v1.3 共用，并发 8。超过 30% 股票取数失败时报错退出，不生成"0只"假报告。
5. 依次执行：基础开关 → 技术条件 → 财务与风险开关 → 观察标签 → 排序截取最多10只。
6. 更新跟踪台账 output/daily/tracking.json，计算 40 日跟踪状态。
7. 生成 output/daily/日期/ 下的 v26.md、v26.json、report.md、feishu-card.json，
   同步飞书多维表格（需 FEISHU_APP_ID/SECRET），推送飞书卡片（Webhook 存在 macOS 钥匙串）。

----------------------------------------------------------------
二、基础开关（不满足直接剔除）
----------------------------------------------------------------
- A股，非 ST / *ST / 退市整理。
- 日K历史 ≥ 260 个交易日，最新K线日期 = 行情数据日。
- 核心市值池：总市值 ≥ 50亿，流通市值 ≥ 30亿，近20日估算日均成交额 ≥ 0.5亿。

----------------------------------------------------------------
三、技术条件 HPRED26（13 项全部满足 = "当前统一观察"）
----------------------------------------------------------------
价格位置
 1. 60日最低点形成于 5–35 个交易日之前。
 2. 收盘价距 60日最低点 ≤ 8%。
 3. 收盘价距 250日最低点 ≤ 15%。
 4. 近5日涨幅 ≤ 5%，近10日 ≤ 6%，近20日 ≤ 7%（3项）。
 5. 近10日没有单日涨幅 ≥ 7.5%。
 6. 均线不过热：收盘价 ≤ MA15×1.03 且 ≤ MA30×1.03（不要求站上任何均线）。

平台结构
 7. 10日振幅 ≤ 14%，20日振幅 ≤ 28%，且满足下面二选一：
    a. 稳定平台：以下6项至少5项，且10日振幅 ≤ 14%、10日收盘区间 ≤ 9%
       - 低点年龄 ≥ 7 日
       - 10日振幅 ≤ 12.5%
       - 10日收盘区间 ≤ 8%
       - 近15日最低价触及低点+4%以内 ≥ 3 次
       - 10日收盘斜率 ≥ -0.30
       - 近5日最低 / 前10日最低 ≥ -2.5%（底部不再下移）
    b. 二次确认：60日内两个局部低点间隔 5–30 日，第二低点距今 ≤ 25 日，
       第二低/第一低 在 -4%~+5%，两低点间反弹 ≥ 3.5%，第二低点后未再跌破 2%；
       同时平台证据 ≥ 3 项、10日收盘区间 ≤ 10%、10日收盘斜率 ≥ -0.70。

量能
 8. 5日均量 ≤ 20日均量，且（5日量中位数/20日量中位数 ≤ 1.05，或当日为温和试探量：
    阳线、量 ≤ 20日均量1.35倍、上影线 ≤ 当日振幅45%）。

指标
 9. 日 RSI14 在 28–45。
10. 周 RSI14 在 24–42。
11. MACD：日线 DIF、DEA 在零轴下，状态为"水下刚金叉 / 水下接近金叉 / 水下低位拐头"；
    周线 DIF、DEA 在零轴下；周线未改善时，只接受日线"水下刚金叉"。

----------------------------------------------------------------
四、右沿观察 HPEDGE26（前3个交易日内曾满足第三节全部条件，今天放宽到以下范围）
----------------------------------------------------------------
- 低点年龄 5–38 日；距60日低点 ≤ 10%；距250日低点 ≤ 15%。
- 近5/10/20日涨幅 ≤ 8% / 10% / 12%；近10日无单日涨幅 ≥ 7.5%。
- 收盘 ≤ MA15×1.03 且 ≤ MA30×1.02。
- 稳定平台或二次确认仍成立；量能条件同第三节第8条。
- 日 RSI 28–50，周 RSI 24–45。
- 日 MACD 水下且改善，周 MACD 水下。
- 日RSI、周RSI、周MACD 至少一项没有继续恶化。
没有近3日触发记录的股票，即使数值落在这个范围也不能进入右沿观察。

----------------------------------------------------------------
五、启动确认剔除（已经走出底部，移出候选）
----------------------------------------------------------------
同时满足以下三类即剔除：
- RSI 偏热：日 RSI ≥ 55 或周 RSI ≥ 50；
- 且（离开底部：距低点 > 12% 或 5/10/20日涨幅 > 8%/12%/18%；
      或 均线收复：站上 MA5、MA10，并站上 MA15 或接近 MA30）；
- 且（放量：5/20日均量比 > 1.15 或中位量比 > 1.10；或日MACD红柱扩张）。

----------------------------------------------------------------
六、财务与风险开关（按"ST风险硬排"，不打分）
----------------------------------------------------------------
- 不通过（剔除）：已ST/退市整理，或可能触发财务类退市、其他风险警示、净资产为负、
  无法按期披露、否定/无法表示审计意见、持续经营重大不确定、资金占用未解决、
  主要账户冻结、立案调查、财务造假、重大行政处罚等。
- 观察（保留但标注原因）：单季亏损、扣非为负、经营现金流为负、利润同比大幅下滑、
  负债率偏高、利润规模过小、问询/减持/质押/担保/诉讼等。
- 公告风险来自最近100条公告标题扫描，不能替代正文核验。
- 财报季：披露截止日前10天仍无业绩信息的停止新纳入；每月20日后仍未披露且跌破MA5，
  降为"财报季风险观察"；跌破MA10/MA15按破位处理。

----------------------------------------------------------------
七、观察标签（只显示，不参与纳入或剔除）
----------------------------------------------------------------
- 大盘环境：中证1000 相对 MA120 的位置（主），上证指数相对 MA60（参考），以及近20日涨跌。
  回测显示：中证1000 在 MA120 上方时出现的底部样本多为相对弱势股，表现明显变差。
- 底部弹性：一年回撤、20日平均振幅、一年内单日涨幅 ≥ 9.5% 的次数、20日上涨日量/下跌日量。
  回撤 ≥ 40% 且振幅 ≥ 3% 且大涨 ≥ 2 次 标为"高弹性"。
- 基本面趋势（只用筛选日之前已公告的数据）：
  净利拐点 = 最近一期净利同比 > 0 且上一期 ≤ 0；
  净利改善 = 最近一期净利同比 > 上一期；
  户数连降 = 最近两期股东户数均减少。
- 行业观察：板块当日领涨股（另一只涨幅 ≥ 3%）、上涨宽度 ≥ 55%、近5日扩散天数。
  东方财富板块接口目前不可用，显示"数据待复核"。

----------------------------------------------------------------
八、排序与截取（排序不是评分）
----------------------------------------------------------------
最多 10 只，同一行业最多 2 只（不足10只时再放开行业限制补足，不放宽任何条件）。
排序依次为：
 1. 状态：当前统一观察 → 右沿观察；
 2. 基本面层级：净利拐点，或净利改善且户数连降 → 只满足其一 → 都不满足；
 3. 一年内大涨次数多（最多计3次）；
 4. 股价低；
 5. 股票代码。
依据：回测中，基本面层级、大涨次数、低股价这三项在 2023-07~2024-12 和 2025 年后
两段都略优于其他排序。

----------------------------------------------------------------
九、40日跟踪（每只入选股票）
----------------------------------------------------------------
- 从首次入选日起跟踪 40 个交易日。
- 破位失效：收盘价跌破"入选前60日最低价 × 95%"，终止跟踪。
- 启动中：期间最高收盘价较首次入选价上涨 ≥ 15%，继续跟踪。
- 到期：满 40 日仍未破位，归档。
- 飞书卡片只列启动中、接近破位（≤1.5%）和近7日结束的股票；完整表在 report.md。

----------------------------------------------------------------
十、v1.3 右侧启动模型（主推来源）
----------------------------------------------------------------
范围：盈利、非ST A股；核心市值池（同第二节）。
技术条件（全部满足 = "右沿初确认"）：
 - 近5日内某日收盘 ≥ 前20日最高收盘（突破平台），且突破前5日内曾满足稳定平台或二次确认、20日振幅 ≤ 28%；
 - 距60日低点 4%–20%，距250日低点 ≤ 30%；
 - 近5/10/20日涨幅 ≤ 10%/15%/20%，近9日单日最大涨幅 < 10%，涨幅 ≥ 7.5% 的日子不超过1天；
 - 连续站上 MA15 和 MA30 的天数 0–4 天，收盘 ≤ MA30×1.06，MA30 近10日斜率 ≥ -5%；
 - 现价在平台上沿 0%–5% 内，突破日量比 0.8–2.5 倍，上影线 ≤ 当日振幅50%；
 - 日 RSI 38–58，周 RSI 32–48；
 - 日 MACD 水下且改善或金叉，周 MACD 水下（周线未改善时只接受日线刚金叉）。
"强启动确认"：在上面基础上更强（距低点 8%–22%、站上 MA15/30 1–5 天、量比 1.05–2.5、
  日 RSI 45–62、周 RSI 35–52、日线刚金叉等）。
行业扩散：只作观察标签，不再剔除（回测中加上后信号减半、超额不变）。
财务与风险开关：同第六节。
主推：基本面层级为第一层（净利拐点，或净利改善且户数连降）。
排序：基本面层级 → 大涨次数多 → 股价低。最多5只，同行业最多2只。
跟踪：同第九节，40日，跌破入选前60日低点5%失效；主推在跟踪表里标★。

----------------------------------------------------------------
