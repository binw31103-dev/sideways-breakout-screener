# 通达信横盘启动选股公式说明

## 一、安装顺序

1. 打开通达信的“公式管理器”。
2. 在“技术指标公式”中新建 `HPBASE`，粘贴 `01_HPBASE_周线辅助指标.txt` 的内容。
3. 在“条件选股公式”中新建 `HPRED231`，粘贴 `02_HPRED231_核心池条件选股.txt` 的内容。
4. 需要测试强化条件时，再新建 `HPRED24`，粘贴 `03_HPRED24_强化实验选股.txt`。
5. 需要跟踪最近严格触发后有限度右移的股票时，新建 `HPEDGE25`，粘贴 `04_HPEDGE25_红框右沿跟踪选股.txt`。
6. 下载完整日线、周线和最新财务数据后，在日线周期执行条件选股。

建议在收盘后、当日日线数据下载完成后执行。盘中运行或尚未下载当日日线时，条件选股可能仍基于上一交易日完整K线，结果不能直接代表当前盘中状态。

必须先建立 `HPBASE`，否则主公式中的 `HPBASE.RSI14#WEEK` 等跨周期引用无法通过。

## 二、默认使用哪个公式

- `HPRED231`：对应当前 v2.3.1 核心市值池，是默认技术预筛公式。
- `HPRED24`：实验版，额外要求 MA30 十日跌幅不超过约3%，并且日RSI、周RSI、周MACD至少一项停止恶化。结果会明显更少。
- `HPEDGE25`：v2.5 右沿跟踪公式。它不替代 `HPRED231`，只选择前三日曾严格满足、当前已经有限度越过严格边界但仍未明显启动的股票。

指定数量不是公式条件。通达信选出多少就是多少，不应为了得到固定数量而修改阈值。

推荐每天收盘后按顺序运行：

1. 运行 `HPRED231`，把结果登记为当日严格触发。
2. 运行 `HPEDGE25`，把结果登记为红框右沿。
3. 两个结果都放入自定义跟踪板块，但保留各自状态和首次日期，最多跟踪 10 个交易日。
4. 再执行行业/概念持续性、财务、公告和人工看图开关。

## 三、已经写入的条件

| 项目规则 | 通达信实现 |
| --- | --- |
| 低点年龄5-35日 | `LLVBARS(L,60)` |
| 距60日低点不超过8% | 当前价与 `LLV(L,60)` 比较 |
| 距一年低点不超过15% | 当前价与 `LLV(L,250)` 比较 |
| 5/10/20日涨幅上限 | 5%/6%/7% |
| 近10日无明显大阳启动 | 单日收盘涨幅不超过7.5% |
| MA5/10早期修复 | 未全站上，或连续站上不超过5日 |
| 未进入MA15/30确认段 | MA30下方，且不明显高于MA15 |
| 平台结构 | 6项证据至少满足5项 |
| 二次低点 | 用前后两个低点窗口近似识别 |
| 量能收缩 | 5日均量不高于20日均量，且最近5日至少3日量能不扩张 |
| 日RSI | RSI14在28-45 |
| 周RSI | 通过HPBASE跨周期引用，RSI14在24-42 |
| 日MACD | DIF/DEA水下，近期金叉或柱线改善 |
| 周MACD | DIF/DEA水下，周线改善；日线刚金叉可暂时容忍 |
| 核心市值池 | 总市值>=50亿、流通市值>=30亿 |
| 流动性 | 20日平均成交额>=0.50亿 |
| 盈利 | `FINANCE(30)>=1000万元` |
| 名称风险 | 排除ST、*ST和退市名称 |

`HPEDGE25` 在上述严格条件之外，内嵌了最近三日严格触发检查，并使用独立右沿上限：距低点 10%、5/10/20 日涨幅 8%/10%/12%、日 RSI 最高 50、周 RSI 最高 45、MA15 上方最多 3%、MA30 上方最多 2%。没有最近严格触发的股票不能直接进入。

## 四、公式无法可靠完成的条件

通达信结果只能作为第一轮技术预筛，选出后仍需执行以下开关：

- 行业或概念中是否已有另一只拉升股票。
- 板块启动是否持续3-5日，是否出现多股扩散。
- 扣非净利润是否为正、经营现金流和负债率是否异常。
- 减持预披露、质押、诉讼、立案、处罚、冻结、审计意见等公告风险。
- 当前图形是否真的是最后下杀后横盘，而不是单边阴跌中的一根反抽阳线。
- 二次低点是否满足真实的时间间隔、中间反弹和后续不破位。公式采用窗口近似，人工看图具有否决权。

## 五、通达信数据口径注意事项

- `FINANCE(40)`、`FINANCE(41)`和`FINANCE(30)`依赖本机财务数据。若未下载或客户端版本字段不同，市值、利润条件可能全部返回0。
- `AMOUNT`按元计算，公式中的50000000代表0.50亿元。
- 跨周期引用依赖完整周线数据。周线未更新时，周RSI和周MACD结果会滞后。
- 每次保存结果时记录选股数据日期。次日盘中出现明显上涨后，应重新检查距低点、5日涨幅、MA15和RSI，不能继续沿用上一日的红框分类。
- `HPEDGE25` 使用 `REF(CORE,1)` 检查前三个交易日的内嵌严格条件。不同通达信版本对跨周期历史引用的实现可能有差异，安装后必须用历史日期回测验证。
- 通达信复权方式、周线合成方式与项目Python数据源可能存在少量差异，因此候选数量不要求完全一致。
- 公式不计算评分，最终只有选中或未选中；人工复核继续使用通过、观察、剔除。

## 六、弹性市值池修改

需要单独运行弹性池时，把主公式中的三项改为：

```text
CAPOK:=FINANCE(41)>=3000000000
 AND FINANCE(40)>=2000000000;
LIQOK:=MA(AMOUNT,20)>=30000000;
```

运行弹性池后，需要排除已经被 `HPRED231` 核心池选中的股票，两个池不能混排。
